# TaskMaster - Full Stack Task Management App

## Features

- User Signup
- User Login
- JWT Authentication
- Create Tasks
- Edit Tasks
- Delete Tasks
- Search Tasks
- Mark Tasks Complete
- Logout

## Tech Stack

### Frontend
- Flutter
- Dart

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Authentication
- JWT (JSON Web Token)
